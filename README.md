Projeto 1: Página Pessoal

Sobre o projeto
O projeto foi proposto como método de avaliação do módulo Programação em JavaScript, tendo como objetivo, criar uma página pessoal utilizando HTML e CSS.
Para o desenvolvimento do projeto, foi utilizado o meu CV como base e foram acrescentados mais elementos, de forma a pôr em prática vários conhecimentos adquiridos em contexto de aula.
Inicialmente, foi criado um esboço através do Stitch. O primeiro prompt utilizado no Stitch foi um pedido de transformação do CV numa página pessoal. Posteriormente, foi pedido ao Stitch a inclusão de outros elementos e algumas alterações a nível visual.
Ao longo do desenvolvimento do projeto, decidi ainda fazer mais alterações e introduzir novos elementos que não estavam previstos no esboço.

Instruções de acesso
Aceder ao esboço do Stitch através do link enviado por email.
Aceder ao repositório GitHub enviado por email. No repositório estarão os ficheiros "index.html", "style.css" e todos os elementos visuais utilizados (imagens e videos).
Abrir o ficheiro "index.html" num browser.

Estrutura
Tendo como base o CV, a estrutura da página contém todas as secções características num CV, organizadas da seguinte forma:
- Cabeçalho: com identificação da pessoa (nome e foto) e menu
- Sobre mim
- Experiência profissional
- Graus Académicos
- Publicações
- Formações
- Hard Skills
- Soft Skills
- Hobbies
- Galeria
- Contactos

Responsividade
Para além da criação da página, ainda foi aplicado o método de responsividade para diferentes tamanhos de ecrã, nomeadamente para ecrãs de tablets (1024px) e smartphones (768px).
